The code in BigmarketAnalysis.py performs Various data science operations such as basic statistics, data visualisation,Supervised and Unsupervised Learning, SMOTE, and Deep Learning  on the BigMarket Dataset(train.csv) to gain various useful insights to the users in order to find best possible shoping store in their nearby region Also a sample Time-series operation is shown which is not related to sales and goal of this project just to understand how time series in data science works.
